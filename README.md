# Potentiële Leefgebieden Maatwerkgebieden

Hier staan alle scripts die gebruikt zijn in het maken van de potentiële leefgebieden en de actueel relevante potentiële leefgebieden (ARPL's).
Daarbovenop staat er een beperkte hoeveelheid data die hiervoor gebruikt worden.
Deze data is beperkt om verschillende reden: er is data die te groot is (100+ MB) om te delen via GITHUB maar ook data die gevoelig is om vrij te geven (waarnemingen en territoria van broedvogels). Deze data zijn nodig voor de ARPL's. Maar in principe is alle data aanwezig om zelf de potentiële leefgebieden te maken.
Het enige dat ontbreekt is de verrasterde bwk-kaart of de opgeknipte delen hiervan. Hiervoor kan men het script (BWK_To_Raster.R) runnen als men de bwk kaart zelf download via geopunt (vrij toegankelijk).
